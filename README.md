# GameStore - Security Cloud

Projeto Full-Stack criado para demonstrar conceitos de segurança no Front-End e no Back-End (Tríade CID), conforme avaliação.

## Estrutura
- **`/frontend`**: Aplicação em React/Vite com validações e tipagem de estado (Checklist 1).
- **`/backend`**: Servidor Node.js em arquitetura profissional (MVC) com balanceamento de carga, proteção de dados sensíveis e verificação de integridade via banco de dados (Checklist 2).

## Como Executar
O projeto está configurado para deploy em nuvem (Vercel/Render). Todas as dependências e comandos necessários ficam dentro das pastas `/frontend` e `/backend` respectivamente.
